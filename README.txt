STORY MIX — ANIME × K-DRAMA

1. Extract the ZIP.
2. In VS Code: File > Open Folder, select Story Mix_Anime_KDrama_VSCode.
3. Double-click index.html to open in a browser, or use Live Server.
4. Keep the images and stories folders together with index.html.

30 books: 15 anime and 15 K-drama. Each book has one original fan-made chapter, an SVG cover, and a supporting SVG scene. These are NOT official stories or official posters.

Features: search, category filter, favorites (saved in browser), dark/light mode, mobile responsive design, story navigation.
